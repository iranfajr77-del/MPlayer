# پشت درهای بسته — Novel Reader

یک اپ اندرویدی مستقل برای مطالعه رمان ۸۰ فصلی، با رابط فارسی و ذخیره خودکار آخرین فصل مطالعه‌شده.

## تصویر برگه اختصاصی
فایل تصویری برگه‌ای که صاحب پروژه انتخاب می‌کند باید با نام دقیق `paper.png` در مسیر زیر قرار بگیرد:

`app/src/main/assets/paper.png`

متن فصل‌ها با رنگ مشکی روی همین تصویر نمایش داده می‌شود. اگر تصویر هنوز اضافه نشده باشد، برنامه موقتاً از زمینه کاغذی ساده استفاده می‌کند.

## ساخت APK
این پروژه یک Gradle Android project مستقل است. از پوشه `novel-app` آن را در Android Studio باز کنید و برای ساخت APK از task زیر استفاده کنید:

`assembleDebug`

## وضعیت فعلی
- چارچوب مستقل اندروید و صفحه مطالعه فارسی ایجاد شده است.
- جابه‌جایی بین ۸۰ فصل و ذخیره آخرین فصل پیاده‌سازی شده است.
- متن واقعی رمان هنوز وارد نشده است.
- تصویر نهایی برگه هنوز باید توسط صاحب پروژه اضافه شود.
