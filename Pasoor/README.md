# پاسور

Android native project (Kotlin + Jetpack Compose) for a Persian Hokm card game.

## Current MVP
- Offline single-player against three bots
- Four seats, two opposing teams
- Standard 52-card deck, 13 cards per player, follow-suit rule, trump and trick winner
- First team to seven tricks wins a hand; match score tracked to seven
- Rotating hakem and editable player name
- Dark black/gold interface and Persian-inspired green table

## Not yet implemented
- Bluetooth host / peer synchronization (internet is not planned)
- Final Persian carpet artwork and generated launcher icon integration
- Advanced bot strategy, special scoring variants, and exhaustive rules tests

## Build
Open this folder as an Android Studio project, or use the repository Actions workflow. Minimum Android 6.0 (API 23).
